description: 按课程规范生成并提交一次 git commit
---

请按课程规范完成一次提交（补充说明：$ARGUMENTS）：

1. 运行 `git status` 与 `git diff`（含已暂存），确认本次改动**只做一件事**；如果混了多件事，先向学生建议拆分提交。
2. 选择 type 与 scope，写标题（4~60 字，说清做了什么，不加句号）。
3. 正文按四项填写：`背景` / `改动` / `验证` / `AI协作`。
   - `验证` 写实际运行过的命令与结果；没有运行过就先运行，不要凭空写“已通过”。
   - 涉及硬件的 `验证` 必须指向 `evidence/` 下真实存在的文件。
   - 本次由 agent 产出的内容，`AI协作` 写“是(工具/模型)；采纳…；人工修正…”，如实反映学生的修正。
4. 先把完整提交信息展示给学生确认，再执行 `git add` 与 `git commit`；**不要使用 `--no-verify`**。若钩子拒绝，按提示修正后重试。
5. 提交成功后，如果今天还没有开发日志，提醒学生收工前运行 `/devlog`。
