## 修正内容

按方向从目的边到另一端逐格处理，数字块和选中士兵交错移动；可行动数量用同一
前到后遍历模拟；伤害 D1 在全部移动后按数字块前方相邻士兵结算；士兵攻击、
无反击、死亡单位阻挡到 `finish()` 的规则保持不变。

## 固定用例（已写入 `tests/test_geyi.c`）

- TC-303-05：数字2(1,1)、红士兵(3,1)，向右选1兵 -> 数字到(3,1)、士兵到(4,1)，
  士兵被数字伤害为 hp6。
- TC-304-05：一行 `N2 B8 N2 . B8 .`，蓝方向右选2兵 ->
  `gy_eligible_count=2`，结果 `. N2 B6 . N2 B6`。
- TC-303-06：士兵在数字让开后进入空格，但同一次行动不再额外攻击前方敌兵；
  数字在 D1 结算时伤害敌兵。
