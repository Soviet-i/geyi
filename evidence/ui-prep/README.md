## 居中与图标中线修正（学生反馈）

第一版截图里人物/机器人图标和“玩家/AI”文字偏右。原因是 `side_box` 的子对象
按按钮内容区绝对坐标放置，而按钮有默认 padding/border。修正为：

- 方框按钮 `pad_all=0`、`border_width=0`；
- 图标和文字改用 `LV_ALIGN_TOP_MID` 对齐；
- `ai_prep_before_center.png`、`ai_prep_blue_before_center.png` 保留偏右对照。

第二版里 AI 机器人图标整体偏高、人物图标偏低。将 AI 图标在 64×64 容器内下移，
使两者包围盒中线一致：

- 人物：约 y=6..56，中心 31；
- AI：约 y=9..53，中心 31；
- `ai_prep_before_align.png`、`ai_prep_blue_before_align.png` 保留对齐前对照；
- `ai_prep.png`、`ai_prep_blue.png` 是最终对齐后截图。
