## 日志中可直接看到的事实

| 角色 | 关键行（以 `135751` 轮为例） |
|---|---|
| A 房主 | `adv started status=0`；`players=2 spectators=1`；旁观者 LEAVE 后 `spectators=0`，重新加入后回到 `spectators=1` |
| B 房客 | `join ack color=1`；`phase=1 cd=3`；`phase=2`；`players=2 spectators=1` |

三轮流程一致：大厅扫描 → A 建房 → B 以玩家加入（红/蓝）→ C 以旁观加入 →
双方准备 `cd=3` → 对局 → 旁观者在 `phase=2` 发出 `leave reason=3 color=255`
（`GY_NET_REASON_LEFT`，即显式点击“退出旁观”）→ 房主/房客观战数 `1→0` →
C 重新扫描并加入 → 观战数回到 `1` → 对局结算“红方胜” → 回房间。

## 验证范围与限制

- 本组日志覆盖：**对局中旁观者主动退出、重新加入，对局不中断，房主/房客观战数同步**。
- `reason=3` 是应用层显式 LEAVE；旁观者 RF 瞬断是另一类场景，分开记录。
- 以上结论按串口可复现的内容记录，作为材料补充，验收状态不变。房主断电、
  旁观者 RF 瞬断、连续两次房主迁移、双旁观者容量按扩展项记录。
