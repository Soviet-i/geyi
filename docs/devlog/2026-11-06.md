## 遇到的问题与解决

1. **`switches_at()` 用了未初始化结构体**
   现象：编译报 `warning C4100: 'step'/'dir_pct' 未使用`，在 `/W4 /WX` 下变错误。
   排查：两个参数"未使用"说明我根本没在函数里用它们——回看代码发现漏了 `sim_init(&s, ...)`，
   `Sim s;` 一直是栈上垃圾。
   解决：补 `sim_init(&s, step, dir_pct, 10, 2)`。**编译告警这次是帮了忙的**：
   它把"参数没用"翻译成了"初始化忘了"。

2. **`switch_latency` 全部输出 -1**
   现象：方向切换延迟全为 `-1`（表示超时未触发）。
   排查：同一个 bug 的另一处——`m_switch_latency()` 里也只写了 `Sim s;` 没 `sim_init`。
   这次没有告警（因为参数都被用到了），是**结果全为 -1 才暴露**的。
   解决：补 `sim_init`。**教训**：测量工具也必须先看"结果是否符合物理直觉"，
   全 -1 或全 0 往往是工具坏了而不是结论。

3. **误触率全 0 时无法自证有效**
   第一版三种噪声模型都报 0，看着像好结论，但**没有任何证据说明工具真的能检测到触发**。
   解决：加**正对照**——"持续定向倾斜 300 ms"必须 100% 触发。
   加了之后三种 0 才有意义。这是本人要求补的，不是 agent 主动想到的。

4. **边界扫描比"误触率"更有信息量**
   只报"噪声不触发"说服力有限。补了 hold_ms 扫描（50~300 ms），
   测出**最小有效保持 200~220 ms**，这才是误触防护的机制所在。
