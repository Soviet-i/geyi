## 遇到的问题与解决

1. **commit-msg 钩子把署名当占位符**：`hw` 类型的正文四项都会被检查，末尾
   `Co-Authored-By: ... <noreply@...>` 的尖括号被 `PLACEHOLDER_RE` 判为 `<占位符>`。
   没有修改钩子或使用 `--no-verify`；把署名 trailer 放在正文第一段（标题空行之后），
   仍保留在提交信息里，四项正文保持干净。
2. **Git Bash 没有 SDK 环境**：`check_env.py` 报 SIFLI_SDK/scons/ARM 编译器缺失；
   改用 PowerShell 执行 SDK 的 `export.ps1` 后再跑 `check_all.py --final`。
   scons 判定工程已是最新，`main.bin` 时间戳/哈希未变（`4e51a876…`），
   说明本次只有文档改动，归档固件仍是学生验证过的构建。
3. **11-14 日志的边界容易写过头**：日志里 `leave reason=3` 是应用层显式退出
   （`GY_NET_REASON_LEFT`），不是无线瞬断。README 与 manifest 都明确写成“显式退出后重新加入”，
   避免把 RF 瞬断、房主断电等扩展项误写成已通过。
