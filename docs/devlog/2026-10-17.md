   `outcome != PLAYING` 时不换手），negamax 却对终局分数再取负，导致“立即
   获胜”被算成负分。修正为：终局子局面直接取该走子方视角的分数，不再递归
   取负；补充一步获胜测试。
2. 字体生成失败：`SIFLI_SDK` 未设置，默认 `D:\sifli\SiFli-SDK` 不存在，
   且 SDK `export.ps1` 依赖的 `uv` 当前不在 PATH。没有改系统环境；定位到
   实际 SDK `D:\IDE\OpenSiFli\SiFli-SDK\v2.5.1` 和其管理的 Python/scons/
   ARM GCC，手动设置进程级环境后完成字体生成、桌面构建和固件编译。
3. 模式页新增两个按钮后，旧桌面测试的点击坐标失效；更新坐标并新增 AI 模式
   测试与截图。
4. 仍保留 SDK 上游链接警告（RWX LOAD 段、newlib `_close/_lseek/_read/_write`
   未实现、ftab 入口符号），未屏蔽；编译日志为原件。
5. 未解决/待确认：本地 `origin` 是 `freewind12/geyi`，而文档和 manifest 写
   `Soviet-i/geyi`；提交前需学生确认推送目标，本轮未改文档中的仓库名。

### 吴周锦（参数配置）

1. **我（agent）把参数项数数错了**
   一开始按 9 项写进提案与 PRD，与《想法》稿原文逐条核对后发现是 **10 项**，
   而且 `GyConfig` 缺的是 **4 项**（我漏算了 `search_depth`）。
   解决：改为 10 项 / 缺 4 项，并在 PRD 里补了一张「逐项对照表」，避免以后再靠印象数。

2. **范围表必须与 `gy_init()` 的既有校验对齐**
   `gy_init()` 要求 `cost >= 1`，而我最初的提议把 `GY_COST_MIN` 写成了 0。
   若不改，本模块会产出规则库拒绝的配置。解决：`GY_COST_MIN` 定为 1，
   并在测试里加了「转出的 `GyConfig` 必须能被 `gy_init` 接受」的交叉断言。

3. **MSVC 把常量条件当错误（C4127）**
   `run_host.py` 用 `/W4 /WX`，`if (GY_P_COUNT != 10)` 与测试里的 `CHECK(GY_P_COUNT == 10)` 都被判为警告→错误。
   解决：把"参数条目数必须与枚举一致"改成**编译期断言**（typedef 数组技巧），
   测试里改成运行期统计"有名字的参数个数"。

4. **`run_host.py` 打印 MSVC 输出时抛 `UnicodeEncodeError`（GBK）**
   根因：Windows 控制台默认 GBK，而 MSVC 输出里有替换字符。
   解决：执行时设 `PYTHONIOENCODING=utf-8`。这是环境问题，未改脚本本身。

5. **输入测试序列写错（latched 未解除）**
   我第一版行为测试直接上倾斜样例，结果 `s.direction` 一直是 -1。根因：输入模块要求先"回中"
   （`magnitude<=1000`）才能解除 `latched`，`gy_input_selftest()` 也是这么写的。
   解决：测试序列改成"水平样例 35ms → 倾斜 245ms → 试探"。

6. **`check_trace.py` 不识别 `REQ-402/409` 这种缩写**
   它按完整字符串匹配，`REQ-402/409` 只被识别成 `REQ-402`，导致 REQ-409/410 报"测试计划未覆盖"。
   解决：改成 `REQ-402、REQ-405、REQ-409` 与 `REQ-407 与 REQ-410`，`--final` 通过。
