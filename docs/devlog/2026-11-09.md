## 遇到的问题与解决

1. **`git fetch` HTTPS 反复超时**
   现象：`Failed to connect to github.com port 443 after 133456 ms`，`upstream/develop` 停在旧位置。
   排查：GitHub API 可达，说明是 HTTPS/git 传输问题。
   解决：`git remote set-url upstream git@github.com:Soviet-i/geyi.git`，SSH 秒通。

2. **我一开始把归属判断错了方向**
   看到"游戏手感差"就准备直接改，但没有先确认模块归属。查 `docs/00` 的 WBS 和
   `git log -- src/geyi_input.c` 才确认这是殷白玉的 T-02。**先确认归属再动手**，
   否则容易在别人的模块里做无授权的大改。

3. **CANCEL 计数不是好的"卡顿"指标**
   第一版测"每秒选择被打断次数"，结果非单调（0%:124、10%:218），因为 `clear_selection`
   只在已有选中时才发 CANCEL，一旦清掉就不会再发。
   解决：换成"预览可用时间占比"，单调且直接对应"看起来有没有反应"。
