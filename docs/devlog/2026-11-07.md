## 遇到的问题与解决

1. 无代码编译/测试失败。桌面构建正常生成了新的 `geyi-desktop-cn.exe` 并运行
   `--test` 全部 PASS。
2. 自绘图标没有使用图片资源或 LVGL 不存在的 user 符号；用圆/圆角矩形/圆点
   绘制人物和机器人，避免字体缺字和额外 Flash 资源。
3. 图标子对象默认可能拦截点击；统一取消 `LV_OBJ_FLAG_CLICKABLE`，由方框按钮
   接收点击。桌面测试在图标区域点击互换通过。
4. 新布局的真实屏幕居中/裁切/图标辨识度未上板验证，已登记 R-015/R-035。
