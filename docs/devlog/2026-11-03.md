## 遇到的问题与解决

1. **主机验证流程整体中断**
   现象：`run_host.py` 打印前 6 组 PASS 后报 `geyi_balance_scan.c(36): error C2220`，退出码非 0。
   排查：`C2220` 只是"警告被当作错误"的汇总，真正的警告是 `C4996: 'fopen' ... unsafe`。
   根因：`/W4 /WX` + MSVC 对 `fopen` 的安全废弃提示。
   解决：文件内局部 `_CRT_SECURE_NO_WARNINGS`。没有选择改 `run_host.py` 加 `/D`，
   因为那是共享脚本，且并非所有工具都需要；也没有改用 `fopen_s`，因为那会把 gcc 分支写坏。
   **教训**：`C2220`/`C2220` 这类"汇总类错误"必须继续往下找具体警告号，不能只看第一行。

2. **`C4996` 只在 MSVC 路径出现**
   组长 10-31 记录"六组断言 PASS"时用的是 gcc/其他路径或较早的目标列表，所以这个中断没被暴露。
   这说明"某人在自己环境跑通"不等于 CI 跑通；本次修复后 MSVC 路径恢复完整。

3. **SDK 环境实例失效**
   现象：`export.ps1` 报 `environment instance for profile 'default' is missing or invalid for the current checkout`，
   `SIFLI_SDK`/`scons`/`arm-none-eabi-gcc` 全部拿不到，`check_env.py` 判"必需项缺失"。
   排查：`D:\sifli\tools\envs\default` 是空的，工具链虽在但环境清单不匹配。
   解决：`install.ps1 --profile default` 重建（本机设 `SIFLI_SDK_MIRROR_CHINA=1` 走国内镜像），
   装回 gcc 14.2.1 / cmake 3.30.2 / ninja 1.13.2 / sftool 0.2.5 / conan 配置，退出码 0。

4. **PowerShell 5.1 把无 BOM 的 UTF-8 脚本当 ANSI 读**
   现象：第一版修复脚本报 `字符串缺少终止符`，但文件明明没语法错误。
   根因：脚本里有中文，PS 5.1 按 ANSI 解码导致引号被截断。**这是 T0 阶段已记录过的坑，本次又踩了一次。**
   解决：重写为**纯 ASCII** + 带 BOM；后续所有 `.ps1` 一律先写 BOM，正文尽量不写中文。

5. **`.gitignore` 的 `build/` 规则静默吞掉了构建证据**
   现象：提交构建证据后 `git show --stat` 只有 1 个文件（`docs/04`），而我明明 `git add` 了
   `evidence/build/20261103/` 下的两个文件。
   排查：`git check-ignore -v` 显示 `.gitignore:2:build/` 匹配了
   `evidence/build/20261103/README.md` —— **不带前导斜杠的 `build/` 会匹配任意层级**，
   所以 `evidence/build/` 整个被忽略；而且 `git add` 对被忽略的路径**不报错**，只是什么都不加。
   进一步查：`git log -- evidence/build` 为空，说明这个目录以前建过，但**从未成功提交过任何证据**。
   解决：改名到 `evidence/firmware/20261103/` 并补齐提交；登记到 `docs/06` 的 **R-023**。
   **教训**：`git add` 成功 ≠ 文件入库，必须用 `git status` / `git show --stat` 目视确认。
