**本轮定位并修复的根因**：
1. 两块板 NVDS 公共地址相同 → 都用 `#FD5C`；改用芯片 UID 派生 `player_id` 并写入协议。
2. 准备高亮用 `LV_STATE_DISABLED` 修饰整个按钮，主题把两个框都画成白色 → 去掉禁用态，
   按座位 `ready` 单独上色。

**第六轮独立 review 后的追加修正（2026-11-09）**：

- **REJOIN 只发一次**：REJOIN 丢包后客方永不再发，10s 后误显示“对方断线”。改为

- **ConnMap 槽位/连接表溢出**：`conn_alloc` 不再驱逐仍持有 live token 的映射；BLE 第 5

  `host_start`，旧 client 消息不会被当成 host 广播。
- **旁观者房主丢失**：直接 `active=0` 改为先 `client_abort()`，不再留链路到超时。
- **测试加强**：`pc_ble_peer.py` 的 idle-link 断言改为“本次新增日志包含 drop idle
  link 且 PC 端确认断开”，不再用历史全文；edge churn 仍保留。
