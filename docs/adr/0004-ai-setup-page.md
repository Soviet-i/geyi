# 人机对战准备页与先后手交换

日期：2026-10-17。状态：已采纳（学生提出），实现与真机验证待完成。

## 背景

原人机入口在模式页提供“我执红/我执蓝”两个按钮。学生要求按想法稿的准备页
改成“首页 → 开始游戏 → 人机对战 → 先后手准备页”，只实现非联机模式的上半
部分，并提供取消/开始按钮。

## 决策

- 模式页只保留一个“人机对战”入口，进入独立的准备页。
- 准备页左侧红色方框表示先手，默认“玩家”；右侧蓝色方框表示后手，默认“AI”。
- 点击任一方框互换玩家/AI 的先后手，方框颜色仍固定表示红/蓝方。
- “取消”返回游戏模式选择页；“开始游戏”按当前选择初始化新局；AI 执红时先手。
- 每次进入准备页恢复默认“玩家执红”，不沿用上次选择。
- 不实现联机房间、旁观者、准备状态或网络逻辑。

## 备选

| 备选 | 放弃原因 |
|---|---|
| 保留模式页两个“我执红/我执蓝”按钮 | 与想法稿准备页不一致，先后手关系不够直观 |
| 固定人类执红 | 最简单，但不满足“可调换先后手” |
| 完整实现想法稿房间/旁观页 | 本轮是非联机模式，房间与旁观属于联机功能，超出范围 |

## 后果

- 新增一个 UI 容器和 `prep_human_red`/`prep_active` 状态；游戏规则、AI 搜索和
  REQ-316 预览逻辑不变。
- 需要重新生成界面字库并做桌面/真机布局检查；390×450 屏幕上两个方框和底部
  按钮必须不重叠、文字不裁切。
- 准备页是纯 UI 流程，不改变棋盘或 AI 决策；真机截图/操作仍需学生验证。
