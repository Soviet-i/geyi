# ADR-0011: agent 驱动的分层端到端自动化测试

- 状态：已采纳
- 日期：2026-11-10
- 决策人：蔡融汉　协助：Claude Code / deepseek-v4-flash
- 关联需求：NFR-11、REQ-320、REQ-501~REQ-513

## 背景

本项目只有三块黄山派 SF32LB52 实体板，倾斜、KEY2、BLE 联机、旁观、断线重连
都需要真机才能完整走通。此前每一轮修改都依赖学生手动烧录、逐项点击、口述现象，
一轮回归往往要十几分钟，而且容易出现“测试没覆盖客方”“假通过”“问题复现不了”
等情况。学生希望 agent 能自己形成“改代码 → 烧录 → 跑真实输入路径 → 读断言 →
继续改”的闭环，减少人工测试压力；同时不能把自动化的结果冒充成真机验收。

## 备选方案

| 方案 | 优点 | 缺点 | 对需求/风险的影响 |
|---|---|---|---|
| A. 继续纯人工测试 | 不增加测试代码；真机结论最直接 | 每轮都占学生时间；回归易漏；agent 无法自证 | 测试压力大，回归证据不稳定 |
| B. 只做主机纯逻辑测试 | 快、可 CI、无硬件依赖 | 覆盖不到 LVGL/KEY2/BLE/真实时序；客方落子这类问题抓不到 | 不足以保证联机回归 |
| C. 分层自动化：L1 主机 + L2 桌面 + L3 板端脚本；板端只注入输入源，保留原路径 | agent 可闭环；断言可重复；失败日志可保留；真机仍由学生做最终确认 | 需要维护脚本和测试夹具；固件里要留测试入口；BLE 时序仍有 flake | 满足 NFR-11；显著降低人工回归压力 |
| D. 只用 PC BLE 第三设备模拟 | 不占实体板 | 无法覆盖真实 UI/KEY2/倾斜；PC BLE 环境不稳定 | 只能作为补充，不能替代双板/三端 |

## 决策

选择 **方案 C：agent 驱动的分层端到端自动化测试**。

具体边界：

- L1 主机纯 C：规则、输入状态机、参数、AI、协议/房间/app 路由，`tools/run_host.py`
  一键编译运行并断言。
- L2 桌面 LVGL：页面/安全区/按键路径，`tools/build_desktop.py --test`。
- L3 板端：`tools/net_board_test.py`（双板完整套件）、`tools/net_spectator_test.py`
  （三端旁观）、`tools/net_input_test.py`（真实 tilt+KEY2 注入对局）、
  `tools/net_latency_test.py`（加入/关房延迟）。
- 固件测试夹具只替换**输入源**：`gy_net simtilt X Y`、`simkey`、`simoff`、
  `simcoin N`；之后的新鲜度、消抖、倾斜状态机、UI 确认、net_app 路由全部保持原样。
  测试命令 `gy_net info/info2` 只读状态，不直接改棋盘。
- agent 可以自行编译、烧录、跑脚本、保留失败日志；**屏幕像素、触摸手感、倾斜手感、
  马达/灯效、真实 BLE 环境仍由学生确认**，自动 PASS 不等于物理验收。
- 失败记录不覆盖：失败日志、重跑日志、环境问题都保留在 `evidence/`，并在
  `docs/04`/`manifest.yaml` 中如实标注。

理由：这套分层让 agent 能在没有人肉点击的情况下复现“客方预览出现但 KEY2 不落子”
这类真实路径问题（`net_input_test.py` 就是这么定位的），同时把最终物理判断留给
学生；比纯人工可重复，比纯主机更接近真实路径，比 PC 模拟更可靠。

## 后果

- 正面：回归从“学生手动点一遍”变成“agent 跑脚本 + 学生只做最终确认”；失败可复现、
  可留证；客方/换座/放兵/旁观等路径有自动断言；CI 可跑主机层。
- 负面/代价：固件保留测试入口，需在发布说明中标注；BLE 瞬断重连存在时序 flake，
  需要重跑并保留失败记录；脚本维护成本；不能替代真实屏幕/手感验收。
- 需要同步修改：`docs/02` 测试策略；`docs/03` TC；`tests/README.md`；
  `manifest.yaml` 的 `physical_verification`/`test_results`；`evidence/net/`。

## AI协作

agent 提出并实现分层脚本与板端输入注入；学生明确要求“能自动复现就不要让他手测”，
同时坚持真机结论必须由本人确认、不得编造截图/数值。agent 采纳了学生的边界：
自动脚本负责软件路径回归，学生负责物理验收；失败日志与 flake 均保留。
