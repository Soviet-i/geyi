## 想法稿中与人机对战相关的规则（摘要）

- 模式：单机、人机、联机；人机可选择调换人与 AI 的左右顺序（先后手）。
- 棋局为方形 N×N；棋子分为我方单位、敌方单位、数字单位。
- 士兵每次沿倾斜方向移动一格；倾斜角度决定移动的士兵数量，优先移动离
  黄色指示点最近的可移动士兵；同方向从前往后处理，避免被未移动的单位卡住。
- 数字单位按 2048 规则滑动到最远位置，可合并；撞到我方或敌方士兵时造成
  数字大小的伤害；数字单位无敌、不会消失，不显示血条。
- 一次 2048 合并获得金币（一次滑动合并多个数字算多次）；击杀敌方单位获得
  金币；金币足够时进入放置模式，放置士兵占用一次行动并换手。
- 一方所有士兵死亡则游戏结束；双方士兵同时全部死亡为平局。
- AI：含 Alpha-Beta 剪枝的 Minimax；精心设计启发式局势评估；搜索深度限制；
  确保 AI 不做明显愚蠢动作；录视频对比有/无剪枝的性能。
- 自定义参数（包括 AI 搜索深度、缓冲阈值等）属于想法稿的后续参数页；
  本轮 REQ-315 不实现参数编辑。
- 士兵合并、动画等为“进阶功能，暂时不需要实现”，本轮不实现。

## 与当前原型的差异/待确认

- 当前 `src/geyi_game.c` 是个人原型暂定规则：默认 6×6、血量 8、攻击 2、
  放兵 4 金币、合并 +1 金币、击杀 +2 金币、每次有效移动生成一个 2（90%）
  或 4（10%）数字块。
- 当前放兵不生成数字块；想法稿的“每 N 次移动生成一个数字单位”参数未实现。
- 当前只有单机/人机所需的基础规则；联机、自定义参数、士兵合并尚未实现。
- 这些差异需团队/组长确认后再作为正式规则；REQ-315 按当前核心规则实现 AI，
  不擅自改变规则。
