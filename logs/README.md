# logs/ —— agent 会话记录

存放导出的 AI agent 会话原始记录，按日期命名，例如 `2026-10-12_claude-code.md` / `.jsonl`。

## 要求

1. 导出**完整、未经编辑**的会话记录（包含走过的弯路、报错、你的纠正）；不要只截取“成功的部分”。
2. 在 `manifest.yaml` 的 `dev_agent.session_log_path` 中引用。
3. 导出前检查并**删除其中的密钥、令牌、个人隐私信息**（用 `[已脱敏]` 占位），其余内容不要改动。
4. 不同工具的导出方式不同：
   - Claude Code：可用 `/export` 导出对话，或保存终端会话记录；也可在会话结束前让 agent 把本次对话摘要与关键决策追加到当天开发日志。
   - 其他工具（Codex 等）：使用其自带的导出/分享功能；没有导出功能时，复制完整对话保存为 md。
5. 单个文件过大时可压缩为 `.zip` 后放网盘，在此放链接文件。
